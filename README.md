Sorting Visualizer

A Java-based Sorting Visualizer built using Swing and AWT, designed to visually demonstrate how popular sorting algorithms work in real time.

1. About the Project

When I first studied sorting algorithms, I never imagined I’d one day bring them to life visually.
This project showcases multiple sorting algorithms — each represented by colorful bars that rearrange dynamically as the algorithm progresses.

2. Features

Visualizes Bubble Sort, Selection Sort, Insertion Sort, and Merge Sort

Adjustable sorting speed

Adjustable array size

Clean and interactive UI built with Java Swing

Real-time color transitions for comparisons and swaps

3. Tech Stack

Language: Java

Frameworks/Libraries: Swing, AWT
